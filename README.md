# Tally
Sistema de controle de agendamentos.

## Sobre o projeto
O Tally é uma aplicação de agenda que permite o gerenciamento de clientes, serviços e agendamentos.

## Status
🚧 Em desenvolvimento

## Funcionalidades
- Cadastro e manutenção de clientes
- Cadastro e manutenção de serviços
- Registro e consulta de agendamentos

## Tecnologias utilizadas
- Java 
- Spring Boot
- HTML
- CSS

## Como executar
1. Clone o repositório:
```bash
git clone https://github.com/anamariaesp/Tally.git
```
2. Abra o projeto em sua IDE de preferência.
3. Execute o arquivo EstoqueApplication.java.
4. Acesse no navegador:
```text
http://localhost:8080
```
